# Interative Visualization Tool for Homeless Shelter Occupancy

This project presents an interactive data visualization system to analyze and track the occupancy rates of homeless shelters across Alberta, Canada, from 2013 to 2021. We built this interative visualization tool to allow users to visualize shelter capacity and occupancy trends by city, shelter type, and organization and also explore possible correlations between shelter occupancy and unemployment rates. 

This tool built in Python featured an interactive visualizations for capacity trends, comparison between shelter usage and unemployment rates, city-wide and organization-wide breakdowns and an exportable HTML interface. 

The dataset sourced from [Open Government - Alberta](https://open.alberta.ca/opendata/funded-emergency-shelters-daily-occupancy-ab) included information on shelter capacity, overnight occupancy, daytime clients, shelter type, city, date, organization, and shelter name. The second dataset, published by the [City of Calgary](https://www.calgary.ca/research/economic-indicators.html), provided the economic indicators for 2009-2023, from which unemployment rates and population data were extracted for 2013-2022 to assess their correlation with shelter usage. 

We conducted a usability study for the following tasks:
- Look at the overall homeless occupancy trends across the province
- Understand overnight shelter occupancy trends and Capacity for cities in Alberta
- Compare and Analyse the overnight shelter occupancy and unemployment rates in each city.
